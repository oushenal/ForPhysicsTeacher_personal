差　值（误差） —
s近似 = v1Δt + v2Δt + … + vnΔt = Σ viΔt
s精确 = v0t + ½at²　　（梯形面积 = ½(v₀ + vt)·t）
误差 Δs = ½at² / n　→　0　（n → ∞）
提示：每个小矩形代表小球在该 Δt 内做匀速直线运动，其面积 vi·Δt 就是这段时间内的位移。 当 Δt 足够小时，各小矩形面积之和就无限接近匀变速直线运动的真实位移 —— 即 v–t 图线与时间轴围成的面积。
